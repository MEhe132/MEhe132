[Project 4] Safe-Seller-Keep-Alive — Stealth Marketplace Session Manager (Manifest V3)
- Repo URL: https://github.com/MEhe132/Safe-Seller-Keep-Alive
- Stack: JavaScript (ES6+), Chrome/Edge Extension Manifest V3 (`chrome.alarms`, `chrome.power`, Service Workers)
- Summary: Background browser extension for Microsoft Edge and Google Chrome that keeps marketplace seller accounts (G2G & U7BUY) active at randomized intervals without stealing focus.
- Key Engineering Highlights:
  * Randomized Jitter Engine: Uses `chrome.alarms` (600s-1000s randomized intervals) to mimic natural activity in a single background tab.
